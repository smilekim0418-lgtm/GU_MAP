# [기술 기획 보고서] G-map 실질 사업화 단계의 기술·디자인 고도화 및 신규 API 활용 전략

---

## 1. 대규모 서비스(수천 명 동시접속)를 위한 기술 스택 성능 검증 및 GCP 배포 전략

### ① 프론트엔드: Vanilla JS의 리소스 초경량화 효과
* **성능적 우위**: 본 애플리케이션의 프론트엔드는 React나 Vue처럼 무겁고 렌더링 오버헤드가 큰 프레임워크 대신, 순수 **Vanilla JS(바닐라 자바스크립트)**로 작성되었습니다. 
* **동시성 영향**: 프론트엔드 자원은 브라우저에서 다운로드받아 로컬 컴퓨터/스마트폰 리소스로 렌더링되므로, 동시 접속자 수가 수만 명으로 증가하더라도 서버에는 단순 정적 파일 전송 트래픽(Static File serving) 외에는 부하가 전혀 걸리지 않습니다.

### ② 백엔드: 비동기 비블로킹 FastAPI 아키텍처의 동시성 처리 성능
* **FastAPI의 고성능 속도**: Python의 ASGI 규격 프레임워크인 **FastAPI**는 비동기(async/await) 통신 및 httpx 풀링(Pooling) 기반으로 설계되어 있습니다. 기존 동기식 프레임워크(Django, Flask)에 비해 메모리 점유율이 극도로 낮고 요청 처리 속도가 월등히 빠릅니다.
* **API 프록시 병목 최소화**: 외부 API 연동 시 백엔드 단에 캐싱 레이어(MemoryCache)가 이미 내장되어 있어, 중복되는 공공데이터 요청은 외부 서버를 타지 않고 즉각 메모리에서 반환하므로 동시 요청 처리 속도가 최대 0.005초(5ms) 이내로 수렴합니다.

### ③ 리눅스 기반 구글 클라우드(GCP) 배포 및 스케일 아웃(Scale-out) 시나리오
* **GCP 리눅스 컨테이너화 배포**: 애플리케이션을 Docker 컨테이너로 패키징하여 **GCP Cloud Run** 또는 **GKE (Google Kubernetes Engine)**의 리눅스 노드에 배포할 것을 제안합니다.
* **오토스케일링(Auto-scaling)**: 사용자가 몰릴 경우(예: 구미시 출퇴근 정체 시간대), CPU 점유율에 따라 컨테이너 인스턴스가 0.1초 만에 여러 대(2대 ➡️ 10대 이상)로 자동 복제(Autoscale)되어 부하를 분산합니다.
* **GCP Load Balancer 결합**: 분산된 다수의 백엔드 인스턴스로 요청을 균등 배분하여, 동시 접속자 수천~수만 명이 유입되어도 딜레이나 응답 지연 없이 안정적인 기동이 가능합니다.

## 2. 지방도 교통상황 연동 및 맵 후처리(Post-processing) 고도화

### ① 지방도(지방도 903호선 등) 교통상황 범위 확장 방안
* **공공데이터포털 지방도 소통 정보 추가 연동**: 국토부와 경상북도 교통정보센터가 합동 관리하는 UTIS(도시교통정보시스템) 기반의 **'지자체별 주요 간선도로 및 지방도 실시간 소통정보 API'**를 확보하여, 기존 `toggleTrafficLayer` 함수에 복합 오버레이 타일셋으로 바인딩합니다.
* **T-map 가중치 연동**: T-map 최단 시간 경로 탐색 API 호출 시 반환되는 도로별 구간 통행 속도 배열 데이터를 기반으로, 지도의 지방도 벡터 라인 위에 동적으로 혼잡도 색상을 직접 그리는 **'하이브리드 교통 정보 생성 엔진'**을 적용합니다.

### ② 프리미엄 맵 후처리(Style Post-processing) 기획
Leaflet 지도의 투박함을 지우고 최신 MaaS 앱의 프리미엄 감성을 구현하기 위해 **CSS 블렌딩 및 필터 효과(Post-processing)**를 씌웁니다.

```css
/* 다크모드 시 Leaflet 지도 타일의 색감을 네온 글래스모피즘 테마로 강제 변환 */
.dark-theme #map .leaflet-tile-container {
    filter: invert(100%) hue-rotate(180deg) saturate(90%) contrast(95%);
    mix-blend-mode: multiply;
}

/* 지도 위 마커 및 선들을 은은하게 돋보이게 하는 블러/글로우 필터 */
.leaflet-overlay-pane path {
    filter: drop-shadow(0 0 4px var(--primary-color));
}
```
* **효과**: 카카오맵/네이버맵의 단순 2D 그래픽 디자인을 뛰어넘어, 사용자의 테마 설정에 따라 지도가 은은한 다크 그레이 네온 광채를 머금게 하거나 미니멀리즘 크림 베이지 톤으로 자동 렌더링되게 하여 시각적인 극적 만족도를 제공합니다.

## 3. 신규 구미시 API 25종 기반 대시민 융합 맵 서비스 기획 (新GUMAP 킬러 기능)

새로 승인받은 구미시 전용 API 리스트를 융합하여 G-map만의 **독창적이고 공익성 높은 3대 킬러 서비스**를 제안합니다.

```
┌─────────────────────────────────────────────────────────────────┐
│              구미시 특화 신규 API 3대 융합 서비스                 │
├─────────────────────────────────────────────────────────────────┤
│ 1. 구미 안심 귀가 스마트 로드 (CCTV 3종 + 임대사업자 + 아동공원)│
│    - 밤길 안전 가중치 알고리즘을 얹은 "CCTV 밀집 안심 귀갓길"    │
├─────────────────────────────────────────────────────────────────┤
│ 2. 실시간 구미 응급 라이프 맵 (약국 + 산부인과 + 자동심장충격기) │
│    - 야간 약국 / 심장충격기(AED) 최적 동선 도보 라우팅         │
├─────────────────────────────────────────────────────────────────┤
│ 3. 스마트 소음도-레저 트랙 (환경소음도 + 카페현황 + 체육시설)    │
│    - 소음도 히트맵 및 힐링 웰빙 경로 추천                       │
└─────────────────────────────────────────────────────────────────┘
```

### 1) 구미 안심 귀가 스마트 로드 (Safe Return Router)
* **연계 API**: 구미시 생활방범 CCTV, 어린이공원 CCTV, 학교 주변 CCTV, 임대사업자현황
* **컨셉**: 늦은 밤 도보로 길찾기 시, 단순 최단거리가 아닌 **CCTV 감시 밀집도와 가로등 가중치가 가장 높은 "안전한 도보 경로"**를 우선 추천합니다.
* **구현 방식**: 
  - CCTV 3종 데이터의 위경도를 지도에 로드하여 감시 영역 버퍼(반경 30m)를 계산합니다.
  - 도보 라우팅 알고리즘(OSRM) 연산 시, 이 감시 영역 내부의 도로 노선에는 가중치 할인 혜택을 부여하고 감시 카메라가 없는 어두운 이면도로는 패널티 가중치를 주어 에이전트가 가장 안전한 귀갓길로 자동 안내하게 만듭니다.

### 2) 실시간 구미 응급 라이프 맵 (Emergency Medical Link)
* **연계 API**: 구미시 약국 현황, 산부인과의원 현황, 자동심장충격기(AED) 현황
* **컨셉**: 구미시 내의 의료 사각지대 극복을 위한 실시간 위치 추적 및 빠른 보도용 도보 길찾기 지원 서비스입니다.
* **구현 방식**:
  - 심야 시간대에 사용자가 "응급" 모드를 켜면, 현재 위치에서 도보 5분 이내에 있는 가용 가능한 **자동심장충격기(AED)의 위치와 당직 약국(혹은 산부인과/병원)**을 붉은색 네온 아이콘으로 지도에 즉시 하이라이트하고, 해당 지점까지의 최단 도보 화살표 네비게이션을 띄워 줍니다.

### 3) 스마트 소음도-레저 트랙 (Well-being Healing Track)
* **연계 API**: 구미시 환경소음도 현황, 관내 카페 현황, 주요체육시설정보
* **컨셉**: 쾌적한 웰빙 도보 걷기 코스 및 레저 활동을 즐기는 구미시민들을 위한 힐링 지리 서비스입니다.
* **구현 방식**:
  - 구미시 분기별 환경소음도 현황 데이터를 활용하여 소음 수준이 낮은 한적한 행정 구역을 초록색 히트맵으로 뿌려줍니다.
  - 소음이 적은 조용한 산책로를 걸으며, 동선 주변의 주요 체육시설(공원, 테니스장 등)과 분위기 좋은 관내 로컬 카페를 중간 경유지(Waypoint)로 결합하는 맞춤형 힐링 경로 시나리오를 추천합니다.
