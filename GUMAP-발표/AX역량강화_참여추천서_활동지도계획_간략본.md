# AX 기반 역량 강화 프로젝트 참여 추천서 [별지 2] — 활동 지도 계획 (간략본)

**팀 구성**: 팀장 김승현, 팀원 JINZHEXU, 팀원 이주형, 팀원 여태원

본 프로젝트는 금오공대 테크노관 실내지도를 학생들이 직접 구축한 뒤, 그 과정을 AI로 자동화해 캠퍼스와 구미시 대중교통으로 확장하는 과제임. 직접 해 본 작업을 AI로 대체하며 효과를 스스로 측정하는 구조여서 AX 학습 효과가 분명하다고 판단해 지도를 맡고자 함. 지도는 격주 1회 회의를 산출물 시연 중심으로 운영하고, 8주차·13주차 중간 점검에서 달성도를 평가해 필요 시 범위를 조정함. 실내지도 구축 단계에서는 도면 좌표 정합의 오차 기준을 사전에 정해 정량 검증하게 하고, 결과물은 국제표준(IMDF)으로 산출하게 함. AI 자동화 단계는 핵심이므로 지도 비중을 가장 높게 두어, 학습·검증 데이터 분리와 평가 지표 설정을 지도하고 수작업 소요시간을 기준선으로 측정해 효과를 비교함. 팀장 김승현에게는 문제 정의와 일정 관리 및 발표를, 팀원 JINZHEXU에게는 지도 기능 구현과 코드 품질을, 팀원 이주형에게는 좌표 정합과 도면 인식 모델 학습을, 팀원 여태원에게는 공공데이터 수집·정제와 학습 데이터 품질 관리를 중점 지도함. 건축 도면 확보와 학내 실증 승인, 구미시 부서 협의는 지도교수가 공식 요청으로 지원하고, 외부 전문가 자문 2회를 실내공간정보·교통행정 분야로 연계함. 도면 보안과 개인정보 비식별 처리, 공공데이터 라이선스 준수도 지도하며, 종료 후 성과가 학술대회 발표나 소프트웨어 저작권 등록으로 이어지도록 하겠음.
