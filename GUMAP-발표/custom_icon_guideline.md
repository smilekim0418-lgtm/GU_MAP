# 🎨 GUMAP 커스텀 지도 심볼 및 아이콘 제작 가이드라인

본 가이드라인은 사용자가 직접 제작하는 커스텀 로고, 아이콘, 텍스트 라벨을 새롭게 적용한 **라벨 없는 지도 타일(CartoDB Voyager/Positron/DarkMatter No Labels)** 위에 찌그러짐 없이 완벽하게 표출하기 위한 설계 규격입니다.

---

## 1. 기본 아이콘 이미지 제작 규격 (PNG / WebP)

모든 커스텀 아이콘은 브라우저 렌더링 최적화와 모바일/레티나 디스플레이의 선명도를 위해 다음 규격을 철저히 준수해야 합니다.

| 사양 항목 | 세부 기준 | 비고 |
| :--- | :--- | :--- |
| **파일 포맷** | 투명 배경 PNG-24 또는 WebP | 배경색은 반드시 투명 처리 (Alpha 채널 필수) |
| **해상도 표준** | **@1x**: 32 × 32 px / **@2x**: 64 × 64 px | 고해상도 모니터 및 모바일 기기 대응 |
| **디자인 안전 여백** | 상하좌우 최소 2px 이상의 여백(Padding) 확보 | 테두리 잘림 및 찌그러짐 방지 |
| **최대 용량 제한** | 파일당 **10KB 이하** (TinyPNG 등으로 압축 권장) | 초기 지도 로딩 속도 극대화 목적 |
| **컬러 프로파일** | sRGB, 8-bit RGBA | 브라우저별 색상 왜곡 방지 |

## 2. 시설 종류(Category)별 아이콘 크기 권장안

지도 위에서 각 시설물이 중요도에 따라 겹치지 않고 조화롭게 보이기 위한 크기(Leaflet `iconSize`) 및 앵커포인트(`iconAnchor`) 설정 기준입니다.

```
📍 핀형 마커 앵커 (학교, 소방서 등)    🚏 원형 마커 앵커 (정류장 등)
       ┌───────────┐                     ┌───────────┐
       │   Icon    │                     │   Icon    │
       │  (Image)  │                     │  (Image)  │
       └─────┬─────┘                     └─────┼─────┘
             ● [Anchor: 중앙 하단]             ● [Anchor: 정중앙]
```

| 카테고리 | Leaflet `iconSize` | Leaflet `iconAnchor` | 마커 디자인 형태 및 앵커 특징 |
| :--- | :--- | :--- | :--- |
| **🚏 버스정류장** | `[24, 24] px` | `[12, 12] px` | 원형 디자인, 심볼의 **정중앙**이 좌표에 안착 |
| **🏫 학교** | `[28, 28] px` | `[14, 28] px` | 핀/말풍선 형태, 말풍선 **뾰족한 하단**이 안착 |
| **🚒 소방서** | `[32, 32] px` | `[16, 32] px` | 핀/방패 형태, 심볼 **최하단 중앙**이 안착 |
| **🚓 경찰서** | `[32, 32] px` | `[16, 32] px` | 핀/방패 형태, 심볼 **최하단 중앙**이 안착 |
| **🛣️ IC/고속도로 진입로** | `[48, 24] px` | `[24, 12] px` | 가로형 알약 모양 뱃지, **정중앙**이 안착 |
| **🏥 병원 / 🏛️ 관공서** | `[28, 28] px` | `[14, 28] px` | 핀 형태, 심볼 **최하단 중앙**이 안착 |
| **📍 일반 편의시설** | `[24, 24] px` | `[12, 24] px` | 핀 형태, 심볼 **최하단 중앙**이 안착 |

## 3. 도로명 및 번호판 텍스트 라벨 제작 규격

지도의 밋밋함을 채우기 위해 도로 위에 직접 표시되는 텍스트 및 번호판 라벨 규격입니다.

### 🛣️ 고속도로 / 국도 / 지방도 번호판
* **경부고속도로 등 고속도로**: `48 × 24 px` (녹색 배경 `#1a7f37` + 흰색 글씨, 모서리 둥글기 4px)
* **국도 번호판**: `36 × 24 px` (타원형 파란 배경 `#2563eb` + 흰색 글씨)
* **지방도 번호판**: `36 × 20 px` (가로형 직사각형 노란 배경 `#eab308` + 검은색 글씨)

### 🏷️ 일반 도로명 (예: 구미대로, 송정대로)
* **도로명 라벨**: 가로 길이 가변 × 세로 `20 px` 고정
* 글씨 색상 `#334155` (Slate 700), 배경은 반투명 흰색 `rgba(255, 255, 255, 0.85)`에 얇은 테두리(`border: 1px solid rgba(0,0,0,0.05)`)와 그림자를 적용하여 시인성을 높이십시오.

## 4. 줌 레벨(Zoom Level)별 가시성(Visibility) 설정 가이드

모든 마커를 항상 띄워놓으면 지도가 매우 지저분해집니다. 아래 줌 레벨 기준에 맞춰 동적으로 마커가 켜지고 꺼지도록 스크립트를 세팅합니다.

```
 줌 레벨:   6             11            14            16            18      19
 축척:    [시/도]        [구/군]        [동/읍]       [마을]        [건물]
          └─ 고속도로 ──┴─ 국도/IC ───┴─ 학교/소방 ─┴─ 도로명 ────┴─ 정류소 ┘
```

* **Zoom 6 ~ 10** (광역 뷰): **고속도로 번호판**만 노출
* **Zoom 11 ~ 13** (도시 뷰): **국도 번호판, 고속도로 IC 진입로** 노출 시작
* **Zoom 14 ~ 15** (동네 뷰): **학교, 소방서, 경찰서, 종합병원** 노출 시작
* **Zoom 16 ~ 17** (상세 뷰): **일반 도로명 라벨, 주민센터 등 공공 관공서** 노출 시작
* **Zoom 18 ~ 19** (최대 확대): **버스정류장(50m 지점)**, 편의점/약국 등 일반 편의시설 POI 노출 시작

## 5. Leaflet 프론트엔드 코드 적용 예시

사용자가 직접 만든 아이콘 파일을 `icons/` 폴더에 넣고 아래와 같이 적용할 수 있습니다.

### 커스텀 마커 클래스 정의
```javascript
// 1. 학교용 핀 마커 정의
var schoolIcon = L.icon({
    iconUrl: 'icons/school.png',          // 일반 디스플레이용 (@1x)
    iconRetinaUrl: 'icons/school@2x.png', // 레티나/모바일 디스플레이용 (@2x)
    iconSize: [28, 28],                   // 가로세로 크기
    iconAnchor: [14, 28],                 // 마커 좌표 앵커 (중앙 하단)
    popupAnchor: [0, -28]                 // 팝업 창이 뜰 위치
});

// 2. 버스정류장용 원형 마커 정의
var busStopIcon = L.icon({
    iconUrl: 'icons/bus_stop.png',
    iconRetinaUrl: 'icons/bus_stop@2x.png',
    iconSize: [24, 24],
    iconAnchor: [12, 12]                  // 마커 좌표 앵커 (정중앙)
});
```

### 줌 레벨 기반 가시성 제어 스크립트
```javascript
var schoolMarkers = []; // 생성된 학교 마커 배열

// 줌 종료 시 가시성 동적 업데이트
window.map.on('zoomend', function() {
    var currentZoom = window.map.getZoom();
    
    // 학교 마커는 줌 14 이상일 때만 표시
    schoolMarkers.forEach(function(marker) {
        if (currentZoom >= 14) {
            marker.addTo(window.map);
        } else {
            marker.remove();
        }
    });
});
```

## 6. 아이콘 폴더 파일 저장 경로 안내

아이콘 파일은 프로젝트 루트의 아래 경로에 일관성 있게 저장해 주시기 바랍니다.

* 📂 **경로**: `新GUMAP/icons(커스텀 아이콘)/`
* 📄 **파일명 명명 규칙**: `카테고리명.png` 및 `카테고리명@2x.png` (전부 소문자 및 언더바 사용)
  * 예: `school.png`, `school@2x.png`
  * 예: `fire_station.png`, `fire_station@2x.png`
  * 예: `police.png`, `police@2x.png`
  * 예: `bus_stop.png`, `bus_stop@2x.png`
  * 예: `ic_ramp.png`, `ic_ramp@2x.png`
