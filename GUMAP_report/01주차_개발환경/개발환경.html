팀 운영규칙

  1. GitHub 단일 저장소 · 기능 단위 커밋, 큰 기능은 PR 리뷰 후 병합
  2. 주 1회 정기 회의 + 2주 단위 스프린트 리뷰 (회의록 누적)
  3. 스프린트마다 실제로 동작하는 산출물을 시연
  4. API 키는 저장소에 넣지 않고 .env 로만 관리
  5. 월별 활동보고서는 팀장이 총괄, 각자 담당 파트 작성
  6. 일회용 스크립트는 루트에 두지 않고 GUMAP-개발/ 에서

# 2) 실행 — 더블클릭 또는
python server.py            # http://localhost:3000

# 3) 외부 공유(시연용)
