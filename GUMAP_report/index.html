GUMAP 주차별 스냅샷 — 활동보고서 캡처용

계획서(2026.09.04 제출) 추진 일정 1~15주차에 맞춰, 그 주차까지의 기능만 켜진 GUMAP 과 산출물 화면을 모았다. 각 링크는 열리면 캡처할 장면을 자동으로 펼친다.

AX 기반 역량 강화 · 팀 GUMAP
캡처 방법 — 서버를 켠 뒤(G-map-시작.bat 또는 python server.py) 이 페이지를 http://localhost:3000/GUMAP_report/ 로 연다. 브라우저 창을 1600×900 정도로 두면 화면이 한 장에 들어간다. · 앱 화면 주소 뒤에 ?badge=0 를 붙이면 머리글의 "v0.x · N주차" 표시가 빠지고, ?scene=0 이면 자동 장면 없이 기본 화면으로 열린다. · 기존 구현 은 저장소에 이미 있던 기능을 주차에 맞게 켜고 끈 것, 이번에 구현 은 이 스냅샷을 만들며 새로 만든 것(보고서 폴더 안에만 있음), 부분 은 결과가 초안 수준인 것이다.
GUMAP_report · 원본 앱은 건드리지 않았다. 스냅샷용 프론트 사본은 _app/GUMAP-프론트 (변경 줄마다 [REPORT] 주석)
