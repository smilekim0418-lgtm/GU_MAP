A시스템 아키텍처 (4계층)

실내지도 데이터는 오프라인 파이프라인이 IMDF 번들과 경로망으로 만들어 정적 자산으로 배포하고, 경로 탐색은 브라우저에서 수행해 서버 부하 없이 즉시 응답한다. API 키는 모두 서버 .env 에만 둔다.
