# 국립금오공과대학교 공식 캠퍼스맵 설계

작성일: 2026-10-07

## 목적

학교 홈페이지(kumoh.ac.kr)에 공식으로 올릴 **양호동 캠퍼스 전용** 지도를 만든다.
기존 GUMAP 은 구미시 전역 모빌리티 앱이라 범위가 넓고 화면 톤(보라 그라데이션,
글래스모피즘, 이모지 아이콘)이 공식 서비스와 맞지 않는다. 이번 작업은 GUMAP 을
고치지 않고 **별도 폴더 `kit-campus-map/`** 에 새로 만든다. 테크노관 실내 데이터와
실내 길찾기 엔진은 가져다 쓴다.

현재 학교 공식 캠퍼스맵은 일러스트 이미지 1장(번호 1~25)과, 카카오맵 위에 건물
핀·전화번호만 찍은 "캠퍼스투어"가 전부다.

## 범위

포함

- 양호동 캠퍼스 건물·시설 지도 (자체 그린 지도, 외부 타일 없음)
- 통합 검색: 건물(번호·한글·영문) · 학과/부서 · 편의시설 · 테크노관 호실
- 건물 상세 안내 (번호, 이름, 층수, 입주 학과·부서, 연락처, 건물 내 편의시설)
- 캠퍼스 도보 길찾기 (브라우저 계산, 계단 회피 옵션)
- 테크노관 실내지도 (B1F~6F) + 실외→실내 연속 길찾기
- 한국어/영어 전환
- 딥링크·iframe 삽입 모드
- 웹접근성 (KWCAG 2.2) 대응

제외 — 구미시 전체지도, 실시간 버스, AI 비서, 날씨, 드론 정사영상, 3D 타일,
신평동 캠퍼스, 서버 기능 일체.

## 배포 형태 — 정적 사이트

`kit-campus-map/site/` 폴더를 그대로 아무 웹서버에 올리면 동작해야 한다.

- 빌드 도구(번들러) 없음. 바닐라 JS ES 모듈 + CSS.
- 외부 CDN·API 키 없음. MapLibre GL JS 와 Pretendard 글꼴은 `site/vendor/` 에 동봉한다.
  학교 전산망이 외부 스크립트를 막아도 동작한다.
- ES 모듈과 `fetch` 때문에 `file://` 로는 안 열린다. 로컬 확인은
  `python tools/serve.py` 로 한다 (README 에 명시).
- `.gitignore` 의 `lib/`·`build/`·`dist/` 규칙에 걸리지 않도록 그 이름의 폴더는 쓰지 않는다.

│   │       ├── map/       MapLibre 렌더링 (기본지도 · 건물 · 라벨 · 경로 · 실내)

## 데이터

### 원천과 우선순위

| 원천 | 내용 | 쓰임 |
|---|---|---|
| 학교 캠퍼스맵 API (`campusMap.do?mode=buildList`) | 공식 번호 1~25, 한/영 이름, 좌표, 행정실 전화 | **건물 번호·이름의 기준** |
| OpenStreetMap (Overpass) | 건물 외곽선, 도로·보행로·계단, 녹지, 운동장, 주차장, 캠퍼스 경계 | 지도 형상, 보행 그래프 |
| GUMAP 테크노관 IMDF · nav 그래프 | 7개 층 unit/opening, 방 300여 개, 실내 그래프 | 실내지도·실내 길찾기 |
| `tools/sources/buildings.json` (수기) | 학과·부서 배치, 편의시설, 층수, 출입구, 영문명 보완 | 상세 안내, 검색 |

외부 데이터는 `fetch_sources.py` 가 받아 `tools/sources/snapshots/` 에 **커밋**한다.
빌드는 스냅샷만 읽으므로 네트워크 없이 재현된다. 갱신은 fetch 를 다시 돌리고
diff 를 보고 커밋한다.

### 정확성 원칙

공식 서비스에 틀린 정보가 올라가면 안 된다.

- 수기 데이터의 모든 항목은 `source`(출처 URL 또는 "현장 확인") 와
  `verified`(true/false) 를 가진다.
- `verified: false` 항목은 화면에 표시하되, 빌드가 **확인 필요 목록**
  (`kit-campus-map/확인필요목록.md`) 을 만들어 학교 담당자에게 넘길 수 있게 한다.
- 출처 없는 사실을 지어내지 않는다. 모르는 칸은 비운다.

### 산출물 (`site/data/`)

| 파일 | 내용 |
|---|---|
| `basemap.geojson` | 캠퍼스 경계, 주변 도로(맥락용 회색), 녹지, 수면, 운동장, 주차장 |
| `buildings.geojson` | 건물 외곽선 + 속성(id, 공식번호, 이름 ko/en, 분류, 층수, 대표점) |
| `places.json` | 건물 상세 · 학과/부서 · 편의시설 · 출입구 (검색 인덱스 원천) |
| `walk-graph.json` | 실외 보행 그래프 (노드 좌표, 엣지 길이·계단 여부) |
| `techno/` | 테크노관 IMDF(level · unit · opening), 실내 nav 그래프, 방 목록 |

## 지도

- MapLibre GL JS, 배경 타일 없이 GeoJSON 소스만으로 스타일을 짠다.
- 지도 회전(bearing)으로 캠퍼스 긴 축을 화면 가로에 맞춘다. 나침반 버튼으로 북쪽 정렬.
- 건물은 분류별 색(교육·연구 / 행정·지원 / 생활관 / 체육 / 기타)으로 칠하고 공식 번호
  배지를 단다. 기본은 2D 평면이고, "3D" 버튼을 누르면 지도를 기울이고 층수 기반으로
  건물을 돌출한다.
- 정문·후문, 주차장, 캠퍼스 주변 버스정류장(OSM `highway=bus_stop`, 위치만) 을 표시한다.
- **라벨은 HTML 요소로 그린다.** 자체 호스팅 MapLibre 는 한글 글리프 PBF 가 없으면
  symbol 레이어를 못 쓴다. 건물 수십 개 규모라 DOM 라벨로 충분하고, `<button>` 이라
  키보드로 바로 닿는다. 줌 단계·우선순위로 겹침을 줄인다.
- WebGL 을 못 쓰는 환경이면 지도 대신 텍스트 건물목록만 보여준다 (기능은 유지).

## 화면

- 데스크톱(≥ 960px): 상단 머리글(학교명 · "캠퍼스맵" · KO/EN) + 왼쪽 패널 400px + 지도.
- 모바일: 머리글 축소 + 바텀시트(접힘/중간/펼침 3단).
- 패널 흐름: 검색 → (분류 칩 · 건물목록) → 건물 상세 → 길찾기.
- 톤: 정부 디지털 서비스 디자인 시스템(KRDS) 원칙. 무채색 기본에 학교 사이트의 네이비
  (#343b58)·블루(#1c83d0) 만 강조색. 이모지 금지, SVG 선 아이콘 통일, 8px 간격 체계.
  색·글꼴은 `tokens.css` 한 곳에 모아 학교 홍보팀이 바꿀 수 있게 한다.
- 로고는 `site/assets/brand/` 에 파일을 넣으면 쓰고, 없으면 학교명 글자로 대신한다.

## 검색

`core/search.js` — 한글 초성·부분일치·영문·번호 검색.

- 대상: 건물, 학과/부서, 편의시설, 테크노관 호실.
- 정렬: 정확일치 > 접두일치 > 부분일치, 같은 점수면 종류 우선순위(건물 > 학과 > 시설 > 호실).
- 결과는 종류별로 묶어서 보여준다.

## 도보 길찾기

`core/walk-route.js` — 지도를 모르는 순수 모듈.

- 그래프: OSM `highway` 중 보행 가능한 것(footway, path, pedestrian, steps, service,
  residential, unclassified, living_street, tertiary 등)을 캠퍼스 경계 + 여유폭으로 자른다.
  `tools/sources/paths_manual.geojson` 으로 빠진 보행로를 보완한다.
- 출입구: 수기 데이터 → OSM `entrance` 노드 → 외곽선에서 그래프에 가장 가까운 점
  (추정, 확인 필요 목록에 오름). 테크노관은 IMDF 외부 opening 을 쓴다.
- 계산: 다익스트라. 출발/도착은 출입구(여러 개면 전체 최단), 정문, 버스정류장, 내 위치
  (그래프 최근접 점에 연결).
- 계단 회피: `highway=steps` 엣지 제외. 회피 경로가 없으면 그렇다고 알린다.
- 결과: 경로 좌표, 총 거리, 예상 시간(분당 75m), 단계 안내(갈림길에서 방향 전환).
- 테크노관 호실이 목적지면: 각 외부 출입구까지 실외 거리 + 출입구→호실 실내 거리
  (`techno-route-core`)의 합이 최소인 출입구를 고른다. 실외·실내 경로를 이어 표시.

## 테크노관 실내지도

- 건물을 누르거나 호실을 고르면 실내 모드: 층 전환기, 방·복도 렌더, 화장실·엘리베이터·계단 아이콘.
- 방 라벨은 현재 층만, 줌 단계에 따라 표시.
- 실내 길찾기는 `techno-route-core.js`(GUMAP-개발/floorplan 산출물)를 그대로 쓰고
  `build_data.py` 가 복사해 원본과 동기화한다.

## 다국어

- `i18n/ko.json`, `en.json` 에 UI 문구 전부. 데이터의 이름은 `{ko, en}` 쌍.
- 영문명이 없으면 한글명을 쓰고 확인 필요 목록에 올린다.
- 언어는 URL `lang` → 브라우저 언어 순으로 정한다. `<html lang>` 도 바꾼다.

## 딥링크·삽입

URL 이 화면 상태를 그대로 표현한다 (`core/url-state.js`, 뒤로가기 지원).

| 파라미터 | 뜻 |
|---|---|
| `b=2` | 건물 2번 상세 |
| `room=T312` | 테크노관 312호 (실내 모드) |
| `q=도서관` | 검색어 |
| `from=gate&to=b2` | 길찾기 (출발·도착: `gate`, `b<번호>`, `room:<id>`, `here`) |
| `lang=en` | 언어 |
| `embed=1` | iframe 용: 머리글 숨김, 링크는 새 창 |

각 학과 홈페이지의 "오시는 길"에서 `…/?b=2` 처럼 바로 걸 수 있다.

## 웹접근성 (KWCAG 2.2)

학교 홈페이지가 웹접근성 인증마크를 달고 있으므로 같은 기준을 지킨다.

- 모든 기능을 키보드로 쓸 수 있다 (지도 위 건물 라벨도 `<button>`). 초점 표시 분명.
- 텍스트 명도대비 4.5:1 이상. 정보를 색으로만 구분하지 않는다 (분류는 색 + 아이콘·글자).
- 지도의 대체 수단: 같은 정보를 담은 텍스트 건물목록 (스크린리더 사용자 기준 동등).
- 검색 결과·길찾기 결과는 `aria-live` 로 알린다. 바텀시트·대화상자 초점 관리.
- 건너뛰기 링크, 랜드마크(`header`·`main`·`nav`), 의미 있는 제목 구조.
- 확대 200% 에서 깨지지 않는다. 움직임 줄이기(`prefers-reduced-motion`) 존중.

## 오류 처리

- 데이터 로드 실패: 패널에 안내 문구 + 다시 시도 버튼. 지도는 빈 상태로 둔다.
- WebGL 불가: 텍스트 목록 모드 (위 참고).
- 위치 권한 거부/캠퍼스 밖: "내 위치"를 비활성 처리하고 다른 출발지를 고르게 한다.
- 경로 없음: 이유(계단 회피 때문 등)와 함께 알린다.
- 잘못된 딥링크(없는 건물 번호 등): 무시하고 기본 화면 + 짧은 안내.

## 테스트

- `tools/tests/` (pytest): 모든 건물에 공식번호·이름·대표점이 있다, 공식 1~25번이 빠짐없다,
  모든 건물 출입구가 보행 그래프의 같은 연결 요소에 있다, 테크노관 데이터가 원본과 같다,
  산출 JSON 크기 상한.
- `tests/` (node --test): 검색 순위·초성, 다익스트라 정답(작은 그래프), 계단 회피,
  실외+실내 결합, URL 상태 왕복, ko/en 키 집합 일치.
- 브라우저 확인: 데스크톱·모바일 폭에서 주요 흐름(검색 → 상세 → 길찾기 → 실내) 스크린샷,
  키보드만으로 같은 흐름, 콘솔 오류 없음.
